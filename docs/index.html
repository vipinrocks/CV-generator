📄 CVForge

Fill in your details as YAML/JSON — or in the web app — and get a professional, ATS-friendly CV as PDF, DOCX and HTML. Free, open source, fully local.

Try it in 30 seconds

pip install . && cvforge init && cvforge build cv.yaml --theme modern

Prefer a browser? Run streamlit run app.py or use the hosted demo (badge in the repository README).
